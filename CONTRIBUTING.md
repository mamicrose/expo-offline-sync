# Contributing to expo-offline-sync 🚀

First off, thank you for considering contributing to `expo-offline-sync`!

## Development Setup

1. **Clone the repository:**
   ```bash
   git clone https://github.com/mamicrose/expo-offline-sync.git
   cd expo-offline-sync
   ```

2. **Install dependencies:**
   ```bash
   pnpm install
   ```

3. **Build the library:**
   ```bash
   pnpm build
   ```

4. **Run unit tests:**
   ```bash
   pnpm test
   ```

5. **Start the example app:**
   ```bash
   cd apps/example
   pnpm start
   ```

## Pull Request Guidelines

1. Fork the repo and create your branch from `main`.
2. If you've added code that should be tested, add unit tests in `packages/expo-offline-sync/test/`.
3. Ensure the test suite passes (`pnpm test`).
4. Format your commit messages clearly (e.g. `feat: ...`, `fix: ...`, `docs: ...`).
5. Open a Pull Request referencing any relevant issues.
